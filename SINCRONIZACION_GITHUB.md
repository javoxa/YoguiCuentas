# Actualización de YoguiCuentas beta

La carpeta ordenada `Yogui_Cuentas` conserva el historial Git del proyecto y el
destino `https://github.com/javoxa/YoguiCuentas.git`. La actualización se incorpora
a `main` mediante un commit normal.

Ver [SUBIR_A_GITHUB.txt](SUBIR_A_GITHUB.txt) para subirla y para las actualizaciones
siguientes. La instalación actual usa `git clone`, según el README.
El [canal APT futuro](REPOSITORIO_APT_DEBIAN_DEVUAN.txt) todavía no se ha desplegado.

YoguiCuentas continúa como proyecto y software beta. El nombre de la edición
estable se decidirá después de validar esa entrega. No se ejecutó una subida,
se creó una Release ni se modificó el repositorio remoto durante esta preparación.
